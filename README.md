# ダム・オリフィス流出シミュレーター

貯水池からダム壁のオリフィスを通って水が流出する様子を、理論式と2次元の数値計算で見比べるためのWebアプリです。見た目だけの流れではなく、速度場を計算し、その場に沿って粒子を動かします。

## 起動方法

```bash
npm install
npm test
npm run dev
```

開発サーバーは http://localhost:3000 です。本番ビルドは `npm run build` のあと `npm start` です。流体計算は webpack がバンドルする Web Worker で動きます。Turbopack（`next dev --turbo`）では Worker の読み込みが失敗することがあります。

## 操作

画面上部から開始、一時停止、1ステップ、リセット、初期状態への復帰、軌跡の消去、表示の切り替え、パラメータの保存と読込、画像保存、計測履歴のCSV保存ができます。

- 一時停止しても速度場と圧力場は残ります。
- リセットは、いまのパラメータのまま場・粒子・グラフを初期化します。
- 初期状態に戻すは、起動時または最後に適用したプリセットへ戻します。
- 形状や物性を変えると場は初期化されます。シミュレーション速度だけは場を消さず、実時間に対する模擬時間の倍率を変えます。
- 左側がパラメータ、中央が断面、右側が計測、下部がグラフです。
- 速度、水平速度、鉛直速度、圧力、渦度を切り替えられます。ベクトルと流線はボタンで重ねられます。
- プリセットは計算モデルも一緒に切り替えます。各プリセットの説明は選択肢のツールチップにあります。
- 詳しい式と制約は画面の「解説」にまとめています。

## 実装している物理モデル

### 解析モデル

ナビエ・ストークス方程式は解きません。

- 理想流速はトリチェリの定理 `v = √(2gh)` です。
- 出口の一様流速は `C_d √(2gh)`、理論流量は `Q = C_d A √(2gh)` です。
- 貯水池の中は、オリフィス位置に置いた半平面シンクで速度を与えます。壁面境界は厳密には満たしません。
- 下流は一定幅の放物落下です。噴流の広がりや周囲流体の巻き込みは入れていません。
- 圧力は静水圧と、オリフィス内で出口へ向かって直線的に下がるゲージ圧です。
- 水位は `A dh/dt = Qin − Qout` で更新します。`A` は貯水池の長さ×奥行きです。

解析モードで数値流量が理論流量に近いのは、出口速度をその式で与えているためです。独立な検証にはなりません。

### 2次元ナビエ・ストークス

非圧縮の2次元方程式を、直交スタガード格子の射影法で解きます。

1. 移流（RK2セミラグランジュ、または1次風上差分）
2. 粘性（必要なら Smagorinsky 型の渦粘性を加える）
3. 重力
4. 壁と水面の境界
5. 圧力ポアソン方程式（Jacobi、Gauss-Seidel、SOR）
6. 圧力勾配による速度の修正
7. オリフィス出口の流量から水位を更新
8. 速度場を補間して粒子を進める

水面の圧力はゲージ圧0です。水面を横切る速度は許容しますが、水面の形は水平線のままです。水位だけを体積収支で動かします。

自由放出では、数値解の領域は貯水池とオリフィスです。ダムの外へ出た粒子は、最後の速度を初期値にして重力だけで落下します。下流の圧力場や速度場は解いていません。

下流チャンネルモードは、下流も単相の流体で満たし、右端を圧力出口にします。大気中の自由噴流ではありません。

粒子の積分は、オイラー法、2次ルンゲ・クッタ、4次ルンゲ・クッタから選べます。粒子はトレーサーであり、個数は水の質量ではありません。

## 無次元数

代表長さは水力直径です。円形は直径、長方形は `Dh = 2wh/(w+h)` です。

- レイノルズ数 `Re = UL/ν`
- フルード数 `Fr = U/√(gL)`
- ウェーバー数 `We = ρU²L/σ`
- オイラー数 `Eu = Δp/(ρU²)`、`Δp = ρgh`。分母を `½ρU²` にする定義では、理想的なトリチェリ流れで1になります。
- キャビテーション数 `σ = (p_abs − p_v)/(½ρU²)`

レイノルズ数だけで層流か乱流かは断定しません。キャビテーション数は参考値で、ゲージ圧が負というだけではキャビテーションとしません。相変化は解いていません。

粘性係数と動粘度は `ν = μ/ρ` です。水温の近似表から密度、粘性、表面張力、蒸気圧をまとめて入れることはできますが、温度場は解きません。

## 近似と未実装

未実装であることは画面にも出します。

- 自由水面の変形（VOF、Level Set、SPH）
- 表面張力による界面力（係数はウェーバー数だけに使用）
- k-ε などの RANS
- キャビテーションの相変化
- 円形オリフィスの3次元縮流
- 3次元乱流の直接数値計算

Smagorinsky 型は2次元の渦粘性であり、RANSでも解像された乱流でもありません。描画だけの擾乱は速度場に加えていません。高レイノルズ数では、セミラグランジュ法の数値拡散が分子粘性より大きくなり得ます。格子レイノルズ数 `UΔx/ν` をその目安として表示します。

時間刻みは、要求値に対してCFL条件と粘性の安定条件で短くします。1フレームで進める模擬時間には上限があり、描画が遅れても時間刻みを無理に延ばしません。非数や過大な値が出た場合は計算を止めて警告します。

## 検証

`npm test` で次を確認します。

- `v = √(2gh)` と `Q = C_d A √(2gh)`
- 水位の収支 `A dh/dt = Qin − Qout`
- `ν = μ/ρ` と無次元数
- 閉じた水槽で静水圧と重力が釣り合い、流速が残らないこと
- オリフィスを開くと下流向きの流出が出ること
- 発散誤差、壁面法線速度、水位収支誤差
- 格子を変えても有限な流出になること
- 過大な時間刻みが短縮されること

数値流量が理論流量へ収束すること自体は、粘性・2次元・過渡・数値拡散のため、自動テストの厳密な一致条件にはしていません。画面の比で差を確認できます。

## ディレクトリ

- `lib/physics` 理論式、物性、無次元数、時間刻みの制限
- `lib/solver` 解析モデルと2次元ナビエ・ストークス法
- `lib/particles` 粒子追跡
- `lib/visualization` Canvas描画
- `workers` 流体計算のWeb Worker
- `components` 操作、計測、グラフ、断面
- `tests` 物理式とソルバーのテスト

計算エンジンは `initialize`、`step`、`getVelocityField`、`getPressureField`、`getVorticityField`、`getDiagnostics`、`reset`、`dispose` を持ち、描画やUIから式を直接呼ばないようにしています。
